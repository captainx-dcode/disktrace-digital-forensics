# Demonstration Video Plan

Record short, focused demonstrations after the corresponding phase is complete.

1. **Evidence preservation:** identify an image, record size, calculate SHA-256, explain working copies.
2. **Disk and partition structures:** inspect raw image layout and explain sector offsets.
3. **NTFS examination:** explain NTFS volume metadata and MFT observations using actual tool output.
4. **FAT32 examination:** explain boot sector, FAT tables, directory entries, and cluster chains.
5. **Deleted-file recovery:** demonstrate a justified recovery attempt and clearly label its outcome.
6. **Validation and reporting:** validate output, update logs, and show how findings are supported.

For every recording, distinguish observed output from explanation. Use sanitized screenshots and synthetic/public-safe artifacts only.
