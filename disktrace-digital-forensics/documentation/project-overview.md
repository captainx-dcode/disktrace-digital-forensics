# Project Overview

DiskTrace is organized as three sequential investigations: NTFS, FAT32, and raw disk forensics.

This directory contains shared project-level guidance. Investigation-specific commands, observations, screenshots, and findings belong in the corresponding `investigations/` directory.

## Documentation principles

- Record only work actually performed.
- Preserve command output accurately.
- Include screenshots captured from the real lab.
- State assumptions and limitations explicitly.
- Keep original evidence and recovered content out of the public repository.
