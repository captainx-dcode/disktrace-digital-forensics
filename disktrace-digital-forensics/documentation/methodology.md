# Investigation Methodology

Use the following repeatable workflow for each task:

1. **Preparation:** understand the task, lab environment, and evidence source.
2. **Identification:** identify the image format, file system, or data structure relevant to the task.
3. **Examination:** run the specified tools and inspect their output.
4. **Recovery:** attempt extraction only where the task calls for it, keeping output separate from source evidence.
5. **Verification:** check file type, size, and hashes where appropriate. Explain what each check does and does not prove.
6. **Documentation:** record commands, observations, screenshots, and limitations.
7. **Review and commit:** review the documentation and screenshots, then commit the completed task.

Do not mark a task complete until its practical work and evidence capture have been completed.
